# Production Design & Quality Standards

- **No Vibe-Product Aesthetics**: Never use purple/violet gradients, glow blobs, or saturated neon overlays.
- **No Pill-Shaped Buttons**: Buttons must use crisp enterprise radius (`rounded-md`). Cards use `rounded-lg`. Never use `rounded-full` for buttons or interactive badges.
- **Zero Emojis**: Never use emojis as icons or in UI headings/toasts. Use standard SVG icons from `lucide-react`.
- **Zero Em Dashes**: Never use em dashes (`—`) in titles, meta tags, hero copy, or body text. Use `:` or `-`.
- **Authentic Copy**: No vague hero texts, AI buzzwords, fake customer counters, or fake reviews/testimonials. Use precise domain terminology (timetables, vehicle rosters, duty compliance).
- **Zero AI Slop**: No surreal AI photos or stock avatars. Map views use OpenStreetMap.
- **No Cursor or Heavy Scroll Animations**: Interactions must be immediate, snappy, and standard.
- **Launch Checklist**: Favicon must be connected, no "Made with AI" badge anywhere, custom domain setup documented, and `/privacy` and `/terms` must remain functional and linked.
- **Quality**: Always verify code with clean builds and make no mistakes.
